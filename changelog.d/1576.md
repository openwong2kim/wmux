### Fixed

- **Commands run under a shared Codex app-server are no longer attributed to the pane that started the server.** wmux now checks which pane a command really runs under before letting it post to channels, send or update A2A tasks, or type into panes as that pane. A command outside its pane's process tree — under a shared Codex app-server, or under tmux, screen, nohup or setsid — gets an error explaining how to run it from the pane instead. (#1576)

### Changed

- **Channel writes and status updates need wmux running.** `wmux channel post` / `ack` / `join` and `wmux set-status` / `set-progress` are refused when the wmux app is not reachable, because the calling pane cannot be verified. Channel reads still work. (#1576)
