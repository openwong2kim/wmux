### Added

- **A Moa merge decision shows the same facts as the phone's merge sheet.**
  Each merge Moa is asked about now records the pull request's title, head,
  branches, mergeability, merge block, squash permission, check summary,
  squash subject and the GitHub account the merge goes out as, read at the
  moment the lane checked it. Before, the decision kept only the lane's pass
  or fail reasons. The facts are for display: the merge itself still re-reads
  the pull request first.
