### Added

- **Continue on another account works in WSL panes.** Choosing **Continue on <account>** in a WSL pane used to fail with "This pane cannot relaunch Claude on another account". Now it stops Claude and copies the conversation into that account's folder in the same distro, creating the folder if needed. Then the conversation resumes in the same pane. If that account has no sign-in in this distro yet, Claude asks you to sign in. Accounts that sign in with a stored token still cannot be continued in a WSL pane. (#3489)
