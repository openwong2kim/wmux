### Added

- **Agents in different panes can drive different apps at the same time.**
  Computer use used to let one agent at a time send input: after any click or
  keystroke the agent held the desktop for 15 seconds, and every other agent
  was told the desktop was busy. Now only input that has to take over the real
  mouse and keyboard holds the desktop. Input sent to an app in the
  background waits only for earlier actions on that same app, so two agents
  working in two different apps no longer block each other. Actions on one app
  still run in the order they arrive.
