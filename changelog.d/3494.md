### Added

- **Continue on a token account from a WSL pane.** When the account you choose, or your WSL pane, signs in with a stored token, **Continue on <account>** now copies the conversation into that account's folder in the same distro. It then resumes the conversation in a new WSL pane beside the current one, running in the same distro as the same Linux user. The current pane is left as it was. Before this, the move was refused in WSL panes. (#3494)
- **Stored Claude tokens sign in WSL panes without a first-run prompt.** A WSL pane on an account with a stored Claude OAuth token now marks Claude's first-run setup as done in that account's WSL folder, as wmux already does for the Windows folder. Claude then uses the token instead of asking you to sign in. If that folder already has a `.claude.json`, wmux leaves it alone. (#3494)
