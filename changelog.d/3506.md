### Added

- **Switch all open Claude panes to another account.** The workspace right-click menu › **Claude account** now has **Switch open panes to <account>…** for the bound account. After you confirm, each open Claude pane in the workspace continues its conversation on that account, the same way **Continue on <account>** moves one pane, in native and WSL panes alike. Shell panes are left alone; new panes use the new account. A pane in the middle of a turn is skipped, and you get a summary of which panes switched, which were skipped and which failed. (#3506)

### Fixed

- **The workspace account menu no longer shows WSL accounts as "logged out".** In a workspace whose panes run in WSL, an account signed in only inside the distro was marked red "logged out", because the menu read the Windows sign-in. It now shows a neutral "sign-in in WSL" there. (#3506)
