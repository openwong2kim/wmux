### Fixed

- **A host without the desktop app tells the asking PC about a usage limit
  once per reset time.** Claude Code retries by itself after the reset, and
  each retry that hit a limit that had not lifted sent the asking PC another
  notice. Now the same reset is told once. A later reset is told once more,
  with the new time, and that is the one waited for. When the reset time is not
  known, the 6-hour limit counts from the first stop however often the agent
  hits the limit again. (#3329)
