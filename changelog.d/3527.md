### Fixed

- **A state file the daemon can't read at boot is no longer treated as empty.**
  When `sessions.json` or `channels.json` and all their backups were on disk
  but unreadable, the daemon deleted every saved scrollback buffer and could
  replace the channel snapshot with an empty one. It now keeps the files and
  the buffers, skips those steps, and logs one line. A first boot with no
  files still starts empty.
- **The daemon no longer saves over a state file it could not read.** The
  periodic session snapshot skips its save, a pane's retention restamp is not
  written, and channel changes are refused for that run instead of replacing
  the unreadable file with what the daemon happened to hold.
