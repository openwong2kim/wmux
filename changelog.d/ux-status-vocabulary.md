### Changed

- **A task's status dot means one thing everywhere.** The sidebar painted every open task green while the deck's task panel painted the same task from its worker — so one task could read as "done" on one edge of the window and "idle" on the other. Both now read the same rule: amber is running, green is complete, gray is idle, red needs you, and a task handed back for review is amber because it is waiting on the orchestrator, not finished.
- **The sidebar states your tasks in one line instead of listing them twice.** It now reads `Tasks · 3 open · 1 need you`, and clicking it opens the deck's Agent tab on the task list itself. The per-task rows — with the `#` jump to each task's channel — live in that panel now, which is the only place they were ever needed. With no tasks running the sidebar shows nothing at all, instead of a permanent "0 tasks" row.
- **The deck's task panel no longer pushes the conversation off the screen.** It shows five tasks and keeps the rest behind `+N more`; the count in its header still reports the whole ledger. Expanded or collapsed is remembered.
- **An approval prompt is announced at most twice.** The deck header's auto-reject countdown steps aside while the Fleet cockpit's Approvals tab is open, since that list already counts the same deadline down on the row you are answering.
- **The titlebar stopped showing gauges that never said anything.** The memory reading appears only when the footprint is large or has more than doubled since the window started, and the clock is off unless you turn it on in Settings → Appearance (your OS already draws one).
