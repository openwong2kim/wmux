### Changed

- **Browser tools on Windows check who started them.** The first browser tool
  call of an agent session now checks which process started wmux's tools for
  that session. A Codex session on the shared Codex background server is
  refused, as other Codex calls there already were. When the check cannot run
  (for example, a Windows process query times out), browser tools ask you to
  retry the call in a minute instead of guessing the pane. Terminal, channel
  and other tools are unchanged and do not run this check. (#2042)
