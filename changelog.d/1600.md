### Changed

- **`a2a_task_query` returns compact summaries, one page at a time.** Each task
  shows its state, title, parties, timestamps, message count and a short preview
  of its latest message, newest first, with `limit` and a `nextCursor` for the
  next page. Pass `task_id` for the full task, or add `message_id` for a single
  message. Before, the tool returned every task with its whole history. A busy
  workspace hit the 64 KiB result cap, and the cut left JSON that would not
  parse.
- **New-task nudges say what arrived.** The one-line `[wmux] new A2A task …`
  nudge now includes the task title and a short body preview. It is sanitized
  the same way as channel wake previews.

### Fixed

- **An oversized JSON object result stays valid JSON.** When a tool result is a
  JSON object carrying a list, the size cap now drops whole items from that list
  and records the cut in the data, instead of cutting the text mid-value.
