### Changed

- **Hooks for Kiro, Copilot, Gemini and Qwen run a small native program
  instead of Node.** Each hook event used to start a Node process (about
  50 ms and 35 MB); `wmux-native` takes about 10 ms and 1.5 MB, so tool
  calls that wait on a hook return sooner. `wmux setup-hooks` writes the
  native command when the app ships the binary and says which form it wrote;
  otherwise it keeps the Node bridge. On Windows the native binary ships only
  once it is signed. (#3132)
