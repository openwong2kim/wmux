### Removed

- **The six `company_a2a_*` MCP tools are gone.** `company_a2a_whoami`, `_send`,
  `_broadcast`, `_inbox`, `_ack`, and `_status` no longer appear in any tool
  profile. Nothing drove them — no prompt, skill, or documented flow called one —
  while every session paid for their schemas in the `tools/list` it reads before
  doing any work. The full profile drops from 93 tools to 87 and from 76,410 to
  73,610 bytes on the wire; the `core` (47) and `commander` (41) profiles are
  unchanged, because neither ever carried them. Agents that used these should
  use the workspace-level equivalents instead: `a2a_whoami` for whoami,
  `send_message` or `a2a_task_send` for send, `a2a_broadcast` for broadcast,
  `channel_ack` for ack, `channel_read` / `channel_unread` for inbox, and
  `a2a_discover` with `workspace_list` for status.

  **Company mode itself is unaffected** — its UI and the RPCs behind it work
  exactly as before. Only the MCP projection of that surface was removed.
