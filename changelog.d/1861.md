### Fixed

- **Phone answers to long questions no longer bounce.** Answering a Claude Code
  question from the phone failed with "prompt changed" whenever the question was
  long enough to wrap in the terminal, because newer Claude Code draws a wrapped
  question behind a `│` bar. The bar is now read past, so long questions (in any
  language) are answered on the first try, and a question that really changed is
  still refused.
