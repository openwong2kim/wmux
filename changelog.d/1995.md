### Added

- **The Git page's All repos list says whose turn each item is.** The flat list across repos is now split into Needs you, Ready to merge, Agents on it and Waiting on others, newest first within each, with a count on every section and a summary line under the title that jumps to a section. Needs you and Ready to merge start open; the other two start folded and remember how you left them. The turn comes from wmux's own signals (the PR's checks, conflicts and review, and whether an agent pane is working on it), because agents open PRs under your own GitHub account. Another author's PR counts as yours to act on only in repos you can write to, so an upstream project you do not maintain no longer floods Needs you, and a mergeable PR in a repo with no CI shows as ready to merge.
