### Changed

- **An agent that mentions you in a channel you have not joined is now told
  why the mention did not reach you.** Before, the mention came back as
  `not_a_member`, the same as any other workspace outside the room. For those,
  the fix is to invite them, but an agent cannot invite you. It now comes back
  as `human_not_seated`, which tells the agent the mention did not reach you
  and that only you can join, from the wmux desktop app. The mention is still
  dropped and no seat is created for you. This does not yet let a paired phone
  receive channel mentions. (#1652)
