### Fixed

- **A pane whose folder is gone says so.** A terminal whose folder no longer
  exists still opens in your home folder, but now shows a toast once, naming
  the missing folder. This covers new panes and splits, restored panes, and
  panes the daemon brings back after a restart. Before, nothing on screen said
  why the pane was in home. (#3544)
- **Multi Task takes a `/mnt/<drive>/…` repository on Windows.** A WSL-form
  path such as `/mnt/d/src/project` now runs on `D:\src\project` when that
  folder exists. When it does not, the dialog gives the reason. Either way,
  main logs the outcome. (#3544)
