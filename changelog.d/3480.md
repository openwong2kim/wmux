### Added

- **`wmux browser cdp --json` gives a script in a wmux pane a connection to
  that pane's Chrome.** Pipe it into the script, for example
  `wmux browser cdp --json | node drive.mjs`. The script connects with
  Playwright or any other CDP client and sees only the tabs it opens.
  - The token is for one connection, within 30 seconds, and for that pane's
    Chrome. The command prints it only into a pipe, never to a terminal.
  - The Chrome is the pane's own profile, else the workspace's.
  - wmux ends the connection when the browser policy changes, when the pane
    or workspace closes, when the user pauses or takes over a tab in the
    workspace, or when the pane's claim is issued anew.
  - For now it needs macOS or Linux, the Chrome backend on the debugging
    pipe, and target grants, which are opt-in: start wmux with
    `WMUX_CDP_TARGET_GRANT=1`.
  - See [Drive a wmux Chrome profile from your own script](docs/how-to/drive-chrome-from-a-script.md). (#3480)
