### Added

- **Settings › Claude Code › MCP servers › Shared MCP process.** Choose whether agents share one wmux MCP process (On), each start their own (Off), or follow the platform default (off everywhere, as before). The choice applies from the next wmux start. `WMUX_MCP_BROKER` in the app's environment still decides when it is set, and the row says so. `wmux mcp register` and `wmux doctor` follow the same choice.
