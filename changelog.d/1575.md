### Added

- **The sidebar says which pane asked for each fan-out task.** A task row now carries a muted line under its name: `Requested by <pane>` (click to jump to that pane), the pane's name marked `· closed` once it is gone, `Started by you`, `Requested by Orchestrator`, or `Requester unknown`, with the agent doing the task named alongside. Before, a workspace with two agent panes grouped all their tasks under one owner and the calling pane was only in a hover tooltip that could lose track of it after a daemon recovery. The requester is now recorded on the task's lineage stamp by stable pane ids, so it survives PTY rebinds and the pane being closed. Each agent row in a workspace's roster shows `N requested` for its own open tasks, and Fleet's Ready to review rows name the requester too. (#1575)
