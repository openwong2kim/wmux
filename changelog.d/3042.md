### Changed

- **A2A names the terminal by the name you gave it.** Rename an agent in
  its own terminal (Claude Code `/rename koles1`, or a rename in Codex or
  Qwen Code), or rename the tab in wmux, and its A2A messages read
  `Workspace.koles1`. Without a name, they read the pane label or the
  coordinate, as before. In a pane with several tabs the coordinate carries
  the tab's number, so two tabs no longer read the same. `a2a_whoami` and the
  task's metadata now show that same name. Before, only a pane label set in
  wmux reached A2A, and a rename in the agent never showed. (#3042)
