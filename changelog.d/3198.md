### Changed

- **On the debugging pipe, browser tools connect through a token relay.** With `WMUX_CHROME_TRANSPORT=pipe`, an agent's browser tools reach a dedicated Chrome through one wmux relay, using a one-time token from wmux's authenticated pipe. The relay listens on a private Unix socket; it uses loopback on Windows, and elsewhere only when no private temp directory can hold the socket, which wmux logs once. (#3198)
