### Added

- **A protected browser profile runs on the debugging pipe.** With `WMUX_CHROME_TRANSPORT=pipe`, a protected browser profile now runs on the debugging pipe instead of being refused. On the pipe, only wmux sets the browser's download behaviour, a client's new browser context is denied downloads before the client can use it, and context proxy options are refused. (#3181)

### Changed

- **On the debugging pipe, an external client's `Browser.close` is refused on every profile.** (#3181)
