### Changed

- **`task_push` and `task_fetch` compare the recorded origin including its
  port.** wmux now records origin's address as the repository config holds it
  when it starts a task (and when you pick a bot's repository folder), and
  pushes or fetches only while origin still matches it: the same transport,
  host, port and ssh user, the path in any case, and the same server after
  your git URL rewrites. If you move origin to another transport or port,
  pick the bot's repository folder again or start a new task. A task started
  before this update records the address at its first push or fetch when
  origin uses its transport's default port; otherwise start a new task. (#2346)
