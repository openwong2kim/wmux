### Changed

- **`task_push` and `task_fetch` compare the recorded origin including its
  port.** wmux now records origin's address as the repository config holds it
  when it starts a task (and when you pick a bot's repository folder), and
  pushes or fetches only while origin still matches it: the same host and
  port, the same ssh user, the path in any case. Switching origin between
  https and ssh on the same host keeps working. A task started before this
  update records the address at its first push or fetch. (#2346)
