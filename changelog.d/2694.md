### Added

- **Continue a usage-limited conversation on another PC.** The usage-limit card
  now lists the paired PCs that let this one start an agent there. Choosing one
  opens the "Start an agent…" dialog with a note about the work as the first
  prompt, replies going to the held pane, and a wait that ends when the limit
  resets (four hours at most). The note never carries the transcript, paths
  outside the folder or files named like secrets, masks key-shaped values while
  keeping branch names and paths readable, and is sent exactly as the dialog
  shows it. The other PC still decides, with its own approval card. (#2694)

### Changed

- **A URL's password is masked in logs and outgoing text.** Wherever wmux masks
  credentials, `scheme://user:password@host` now reads
  `scheme://user:[redacted]@host`; the user name and host stay. A prompt typed
  into the "Start an agent…" dialog has key-shaped values masked before it
  leaves this PC. (#2694)
