### Fixed

- **Replies from a task on another PC reach the pane that fanned it out.** Before, every reply from a `fanout_start` task on a paired PC or headless box was held as "another program holds the pane" until someone clicked Retry, and its done notice was dropped. wmux now records the calling terminal when the fan-out starts. For a task started before this change, wmux uses the pane's only terminal when an agent runs in it, and never guesses between several. (#3500)
- **The fan-out nudge comes only when someone has to act.** A task on another PC no longer sends "needs input" at each of its agent's turn ends, since that turn's reply already reached your pane. It still does for a question on that PC's screen, and for an agent there that stopped with no reply. The 15-minute idle flag no longer repeats the "updated" you already got. A nudge about a task whose mission was closed since then is dropped. (#3500)

### Added

- **How-to: cap fan-out tasks that run on another PC.** The Live fan-out task limit counts only tasks that run on this PC. The new page lists the limits the other PC sets for itself. (#3500)
