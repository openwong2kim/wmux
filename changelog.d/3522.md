### Fixed

- **Workers wmux starts no longer update Claude Code under your other panes.** Fan-out task panes, and agents started for another PC (headless or in a window), used to run with Claude Code's auto-updater on. An update in any of them rewrote `~/.local/bin/claude`, the launcher every pane runs and per-account launchers wrap. They now start with `DISABLE_AUTOUPDATER=1`, unless your own environment sets that variable, in which case your value is kept. Panes you open yourself are unchanged. (#3522)
- **An agent another PC starts here branches from the repository's default branch, freshly fetched.** Its worktree used to branch from whatever this PC's checkout happened to be on, which could be an old feature branch. It now fetches origin's default branch, with a short timeout, and branches from that. When it cannot fetch (offline, no origin, or a repository config that names how git connects), it branches from HEAD as before and the log says why. (#3522)
- **A task sent to another PC that never arrives now tells you.** A remote send used to answer "queued" and then say nothing if the other PC never got the task, or never handed it to its agent. After 90 seconds with no delivery receipt, the sending pane now gets one notification. It says whether that PC received the task, the link's state, and whether that PC is connected. It is shown once per task, also across restarts. (#3522)
