### Added
- Tool permission prompts can now be answered from the phone. A `PreToolUse` hook holds the gated tool call while the daemon waits for a remote answer, so the prompt that most often stops an agent is no longer a dead end away from the desk. Which tools are gated lives in the daemon config (`wmux gate --list/--add/--remove`) rather than in the hook, so changing it needs no Claude Code restart. The gate arms only inside an interactive wmux pane — `claude -p`, CI and subagents fall through to the normal local prompt — and it fails open on a deadline, a dead session or a daemon restart, so nothing hangs waiting for a phone that never answers. Escape hatches: `POST /api/gate/off`, `WMUX_GATE=0`, or simply waiting for the deferral. Claude Code only for now. (#789)

### Fixed
- `wmux setup-hooks --status` now reports the permission gate alongside the other hook-backed features, so a partial install is visible instead of reading as healthy. (#789)
