### Fixed

- **Messages wait for an agent that is ready for them.** A task, reply, mention, hand-off or scheduled prompt goes into a pane only when wmux can confirm an agent is running there and its input box is a plain prompt. Otherwise the delivery waits, and the sender is told it is held until an agent is ready in the pane. Agents whose input box wmux does not recognise yet get a one-line pointer to the task instead of its text.
