### Fixed

- **Messages wait for an agent that is really there.** A task, reply, mention or hand-off sent to a pane is typed only when wmux can confirm an agent is running there: a tracked agent process in the terminal's foreground, or, where no process can be attributed (an SSH session, for example), the agent's input box on the current screen. Before, a pane whose agent had ended or been suspended could still be typed into because its title still named the agent. Now nothing is typed, the sender is told the delivery waits for an agent in the pane, and a message from another PC is held until one is there.
