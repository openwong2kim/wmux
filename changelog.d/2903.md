### Added

- **A Linux PC added over SSH can run its terminals on the Rust engine.** The
  wmux server that "Add PC over SSH" installs now includes the Rust terminal
  engine, on x64 and arm64. To use it, write `{"engine": "rust"}` to
  `~/.wmux/terminal-core.json` on that PC, or start its background service
  with `WMUX_TERMINAL_CORE=rust`, then restart the service. Before, the server
  could only use the Node engine. Node stays the default, and is used when the
  Rust engine cannot load. (#2903)
