### Fixed

- **The sidebar branch follows checkouts again in folders reached through a
  Windows short name.** If a pane's working directory was spelled with an 8.3
  short name (for example `C:\Users\JOHNSM~1\...`, which is how Windows often
  spells `%TEMP%`), the app's file watcher reported garbled file names. The
  branch shown for that pane then stopped updating after `git checkout`. wmux
  now watches the directory's full long path. (#1656)
