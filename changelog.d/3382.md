### Added

- **`fanout_start` can place tasks on any paired PC.** With `pc: "any"`, each task goes to the online paired PC that offers the folder for Claude and has the fewest of your open tasks there. Tasks other PCs sent to it are not seen. When that PC answers that it is full, the task is held with no request out, and calling again with the same key places it on a PC with room. A task held for an hour fails. Naming a PC works as before. If you go back to an older wmux while such a task is held, the older wmux drops that task's row when it reads the task list. (#3382)
