### Added

- **Open a workspace folder from the sidebar.** Every workspace row now carries a
  folder button that reveals its working directory in the OS file explorer, and
  the right-click menu gained an **Open with…** submenu that lists the editors
  actually installed on the machine — VS Code, VS Code Insiders, Cursor,
  Windsurf, Windows Terminal. Before this you had to copy the path out of the
  session info and paste it somewhere else to get at the files. The detection
  runs asynchronously and probes every candidate at once, so opening the menu
  never stalls the terminals, and a folder that cannot be opened says so in a
  toast instead of swallowing the click. (#702)
