### Added

- **Open a workspace folder from the sidebar.** Every workspace row now carries a
  folder button that reveals its working directory in the OS file explorer, and
  the right-click menu gained an **Open with…** submenu listing the editors
  actually installed on the machine — VS Code, VS Code Insiders, Cursor,
  Windsurf, Windows Terminal. Before this you had to copy the path out of the
  session info and paste it somewhere else to get at the files.

  Detection runs asynchronously and probes every candidate at once, so opening
  the menu never stalls the terminals, and each launcher is remembered by the
  absolute path `where.exe` reported rather than by name — most of these editors
  ship as a `.cmd` shim, which Windows cannot start from a bare name and which
  Node refuses to execute directly, so they are dispatched through `cmd.exe`
  with each argument quoted. A folder that cannot be opened says so in a toast
  instead of swallowing the click. (#702)
