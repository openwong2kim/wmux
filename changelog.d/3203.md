### Fixed

- Microsoft Edge started by wmux (the dedicated profile and protected profiles) no longer signs itself in to your Microsoft or work account and no longer syncs. On a PC signed in with such an account this also stopped protected Edge profiles from starting.

### Added

- `wmux doctor` says when wmux's Edge profile is signed in to a Microsoft account, so agents using it carry that sign-in. If you didn't sign it in yourself, sign it out in edge://settings/profiles.
