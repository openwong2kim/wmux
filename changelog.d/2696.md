### Changed

- **LanLink listens only on a Private network.** On Windows, LanLink now reads
  the network type of the adapter you selected and opens its port only when
  that network is set to Private. On a Public or Domain network, an adapter
  with no network profile, or when the type cannot be read, it stays closed,
  and Settings > LAN and the Remote page's LAN pairing say why in one line,
  with what to change. Before, that check never ran. LanLink also no longer
  tries to add Windows Firewall rules, which needed administrator rights wmux
  does not have. macOS and Linux have no network type, so LanLink there keeps
  listening on the adapter you select. (#2696)
