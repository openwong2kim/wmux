### Changed

- **Linux reads the process table natively instead of starting `ps`.** Stopping a pane's process tree, stopping an agent, the agent tracker, the paste check for a remote shell and the screen-reader check used to start a `ps` process for each read. They now read the process table through wmux's native core: one table read takes about half a millisecond instead of several, and stopping a tree no longer starts a `ps` for each read. If the native read is unavailable, wmux falls back to `ps` as before. `WMUX_NATIVE_PROCESS_TABLE=off` keeps the old path.
