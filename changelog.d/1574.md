### Fixed

- **Commands run under a shared Codex app-server are no longer attributed to the pane that started the server.** wmux now starts the shared Codex background server without any wmux settings. If a server started by an earlier version is still running, wmux restarts it on the next Codex launch when no Codex pane is open; while Codex panes are open it leaves the server running and shows a one-time notice explaining how to stop it (`codex app-server daemon stop`).
