### Added

- **Panes warn when sibling worktrees touch the same file.** While two or more
  panes work in separate worktrees of one repository (fan-out tasks or your own
  worktree panes), wmux dry-runs a merge of each pair every 2 minutes and when
  an agent finishes a turn, and both panes show a quiet "Same file as #w1-2"
  in their tab strip — in the caution colour when the merge would conflict.
  Hover or click it for the files; Start merge opens the Git page's merge
  session for that worktree. Before, the clash showed up only once a merge
  started. The check is read-only (`git merge-tree` with a throwaway object
  directory; no checkout, index or branch is touched), runs one git process at
  a time per repository, and can be turned off or slowed in Settings › General
  (#3485).
