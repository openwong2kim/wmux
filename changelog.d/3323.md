### Fixed

- **A task sent to a host without the desktop app no longer stays working
  forever when that host's agent hits its usage limit.** The asking PC is told
  once that the agent is at its limit and until when. After the reset, the host
  closes Claude Code's usage-limit menu if it is up and types "continue" once,
  unless the agent already went on by itself. If the agent has still not gone
  on 15 minutes after the reset, or 6 hours after the limit when the reset time
  is not known, the task ends as failed with the reason, and the agent is left
  running. (#3323)
