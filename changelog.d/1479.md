### Changed

- **The welcome dialog and the onboarding tour match the rest of the app.**
  Both used monospace text, green borders and several solid amber buttons,
  and the tour's Next button was filled blue. They now use the app's UI font
  and panel style, and each state has a single highlighted action: for
  example, Install hooks when hooks are missing, otherwise Try sample task.
  The sample task card and the tour steps show a short looping clip of the
  feature. The clips show a still image when the system asks for reduced
  motion. (#1479)
- **The settings icon is a gear.** It used to look like a sun, which read as
  a brightness control. (#1479)
