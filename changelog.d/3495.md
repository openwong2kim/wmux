### Added

- **The wmux usage line in WSL panes.** Claude in a WSL pane now shows the same line under the input box as in a Windows pane: the model, the account, context use, and the 5-hour and weekly usage. It also reports that usage to wmux. If your own Claude settings or the project's settings already set a status line, yours is kept. (#3495)

### Fixed

- **WSL panes no longer count their usage toward the wrong Claude login.** A WSL pane's Claude usage used to be read as the Windows default profile's when the pane named no account folder. That could make unattended work wait for the wrong 5-hour window. WSL usage now stays with the pane that reported it, kept apart per distro and Linux user. The Windows account readings that quota switching and the usage reserve use come only from Windows panes. (#3495)
- **agy launches in WSL panes are no longer held by the agy account gate.** wmux switches agy accounts through the Windows sign-in, which agy in WSL does not use, so wmux no longer switches accounts for an agy launch in WSL or holds it. (#3495)
