### Added

- **Drive a remote-box agent over SSH.** Declare a pane with `kind: "ssh"` in
  `wmux.json` and wmux opens an SSH channel to a box you already own instead of
  a local shell. The remote pane is a first-class citizen — scrollback, OSC 133
  agent detection, notifications, loops, Fleet View, and channels all work,
  because only the transport changed, not the data plane. `system.capabilities`
  now advertises `transports: ["local","ssh"]` so clients can feature-detect it.
  Before, every pane was a local `node-pty` child; now a `SessionProcess`
  interface lets `node-pty` and `ssh2` back the same surface.

### Security

- **SSH host keys are verified.** First connect to a host records its key
  fingerprint in `~/.wmux/ssh-known_hosts`; a later connect to the same host
  with a different key is rejected (fail-closed TOFU). Private-key paths in
  `wmux.json` are pointers only, never the key bytes, and `~` is expanded. A
  failed connect can no longer strand the pane as a zombie. (#814)
