### Added

- **`wmux daemon headless prune [--dry-run]`.** On a headless box, removes the worktrees ended agents left whose work is safe elsewhere: clean, with HEAD and the branch tip pushed or brought back by the asking PC. It uses `git worktree remove`, never forced, and lists every worktree it keeps with the reason. Before, each one had to be removed by hand. (#3497)
- **Headless starts get `WMUX_TASK_PORT`.** An agent another PC starts on a headless box gets a free port from its worktree's `fanout.portRange`, as a desktop fan-out task does. No two agents on the box get the same port. (#3497)

### Fixed

- **A headless agent that finished and was then ended no longer shows as failed.** The box's link end could beat its cancel to the asking PC, which then failed the task and alerted. The fan-out row now ends cancelled, and the agent's reply stays on the task. (#3497)
