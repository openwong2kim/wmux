### Changed

- **Terminals run on xterm.js 6.1 (beta).** wmux moves its terminal engine and every add-on to the 6.1 beta line, pinned to exact versions built from the same upstream commit, as the groundwork for the kitty keyboard protocol. Nothing should look or type differently: the two new query replies 6.1 would send on its own (terminal version and color scheme) stay off, and the WebGL glyph-atlas and search fixes wmux carries are re-applied on top. The inline-image fix wmux used to patch in (#1925) now comes from upstream. (#1958)
