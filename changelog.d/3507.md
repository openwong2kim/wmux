### Changed

- **The chat view folds a finished turn under its prompt.** A settled turn
  reads as the prompt, one quiet line ("Worked for 2m 14s"), then the answer.
  The tool calls and the notes written along the way open from that line. The
  turn that is running stays open. (#3507)
- **Each run of tool calls in the chat view is one line.** It reads as a
  sentence, such as "Read 3 files, edited 2, ran 1 command".
  - A single call shows its own command.
  - Paths are shown relative to the chat's folder.
  - Failures are counted in red, and a finished run gets one muted check
    instead of a green tick per call. (#3507)
- **The "Chat only" badge sits in the pane header** instead of a row of its
  own above the conversation. (#3507)
- **An approval in the chat view sits above the composer,** with the command
  inside it. A command that can delete files reads red and defaults to Deny.
  Esc denies and Cmd/Ctrl+Enter allows, from an empty composer too; a draft
  in the composer keeps both keys, and a command that can delete files is allowed only
  by its button. (#3507)
- **Links in chat answers open in the browser** when clicked. (#3507)
- **A chat error is written in words,** with the raw text under Details and
  Retry on the newest failed turn. (#3507)
- **A sent chat message shows what it carried** above the bubble: an image as
  its picture, any other file as a chip with its name. (#3507)

### Fixed

- **A failed chat turn no longer shows the done check** in the sidebar and
  Fleet. (#3507)
- **A chat call that a stop or an error cut short reads "Stopped"** instead
  of looking finished. (#3507)
- **Chat code blocks keep their file name and always show Copy,** and Korean
  text in them stays in the monospace column. (#3507)
- **The chat column lines up with the composer** whether or not it scrolls.
  (#3507)
- **"Jump to latest" shows whenever you have scrolled up in a chat,** not
  only when something new arrives. (#3507)
