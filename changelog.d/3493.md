### Added

- **The Windows taskbar button shows the unread count and when agents are
  running.** The same number as the macOS Dock badge now appears as an overlay
  icon on the wmux taskbar button (1–9, then "9+"; gone at 0). The button also
  shows a progress state while any agent is running. Before, Windows showed the
  count only in the tray tooltip. Settings › Notifications › "Show unread count
  on the taskbar button" turns both off (#3493).
