### Fixed

- **Stalled web streams release their resources.** Device SSE and media transfers share a concurrency ceiling; operator remote panes are exempt. Transfers stop when backpressure cannot clear within 60 seconds, and SSE connections rotate after five minutes without a drain event, even if heartbeats can still be queued. Response timers start when output begins, images respect backpressure, and pane streams allow larger bursts with logged closure reasons. (#1540)
