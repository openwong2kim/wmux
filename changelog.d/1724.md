### Added

- **Phone read and approve for chat v2 conversations.** A pane whose
  conversation the daemon runs itself (chat v2) now shows up in the phone's
  Chat view: its replies, tool calls and results, subagent work, task lists,
  plans and pending questions read like any other conversation, and its tool
  permissions can be answered from the phone's approval list. Sending from the
  phone stays off for these panes, and starting a second agent in the same pane
  from the phone is refused. A phone that declared Stop support can interrupt
  the running turn.
- **Hand a chat v2 conversation to the terminal.** The daemon can now stop the
  chat agent, confirm its process has exited, mark the chat as handed off, and
  resume the same conversation in the pane's terminal with `claude --resume`.
