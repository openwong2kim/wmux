### Added

- A `+` after the last tab in a pane opens a small menu to add a terminal or a
  browser tab to that pane. Adding a second terminal to one pane has always
  worked from the keyboard; there was no way to discover it (#909).

### Changed

- The new-browser button moved out of the pane action cluster and into that
  same `+` menu. Both entries create a surface in the pane, so they now sit
  together; the cluster keeps only the actions that act on the pane itself —
  split right, split down, and zoom (#909).
