### Added

- **Ask another PC to start an agent from a branch you name.** `remote_spawn` takes an optional `base`: a branch of that PC's origin. The agent's worktree is fetched from it instead of from the default branch. This needs wmux on that PC to be this version or later. An older one is not sent the field: the request is refused at once with a message saying to update it there, or to leave `base` out. (#3525)
- **When another PC starts your agent from its own HEAD, you are told why.** If that PC could not fetch the branch (offline, no origin, or a repository config it does not fetch with), its reason now comes back with the start. It shows as `baseNote` in `remote_spawn`, on the `fanout_start` task row and in the log. (#3525)

### Fixed

- **Quick launch, company seats and WSL task panes now also start Claude Code with its updater off.** They join fan-out and remote starts in setting `DISABLE_AUTOUPDATER=1`, so an update in one of them no longer rewrites the launcher every other pane uses. A value you set yourself is kept. In WSL, the setting crosses into Linux only for task panes, never for an ordinary WSL pane. (#3525)
