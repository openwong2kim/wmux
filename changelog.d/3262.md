### Fixed

- **The Windows installer no longer stalls for about 16 s before wmux opens.**
  Since 4.11.0 the installer waited out a 16 s limit near the end of every
  install and update before it went on. On a first install the step that
  creates the Desktop shortcut came after that wait and was cut off, so no
  shortcut was made. The install step now finishes in a few seconds and
  creates the shortcut again.
