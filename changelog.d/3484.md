### Fixed

- **The MCP process no longer keeps a copy of every browser response it sees.** Network capture used to read each textual response body as it arrived, and Playwright held on to that copy for as long as the page stayed open. A session that used browser tools heavily could push the MCP process past 700MB over a couple of days, and with the shared MCP broker one process carries every session's browsing. Bodies now stay in Chrome, which keeps only a bounded amount, and `browser_response_body` fetches one only when you ask for it. If Chrome has already let it go, for example because the page navigated away, the tool says the body is no longer available. Every 5 minutes the MCP process also logs its memory use to stderr, and it warns when external memory passes 300MB. (#3484)
