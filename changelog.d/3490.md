### Added

- **Install approvals say which packages the project doesn't have yet.** When an agent asks to run `npm`/`pnpm`/`yarn`/`bun` add or install, `npx`/`bunx`/`pnpm dlx`, `pip install`, `uv add` or `cargo add`, the approval record now lists the packages that are not in the project's `package.json`, Python or Cargo manifests or their lockfiles, and the wmux phone app's approval card can show that in one line. Agents sometimes invent package names, and attackers register them. The check reads only local files up to the repo root, sends nothing anywhere, and says nothing when there is no manifest to compare with. It never changes the risk verdict, the buttons or the lock-screen push. Turn it off in Settings → Claude Code → "Note new packages on install approvals"; it is on by default. (#3490)
