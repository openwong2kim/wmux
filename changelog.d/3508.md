### Added

- **Chat: change the model and effort mid-chat.** Between turns, the model and effort chips change a running chat. Claude Code switches in place, or restarts on the same conversation when it has to; Codex changes them on its thread. Before, both were fixed once the chat started. (#3508)
- **Chat: a `/` menu.** Typing `/` lists the chat's commands (model, effort, continue in Terminal) and the agent's own skills, with arrow keys and Enter. (#3508)
- **Chat: attach any file, also to the first message.** A `+` button, a drop or a pasted image adds it. Images show a thumbnail; any other file goes to the agent as its own path, so it edits the real file. Before, only images could be attached, and only once the chat had started. (#3508)

### Changed

- **Chat: one Send/Stop button, and queued messages wait above the composer.** While a reply runs, the send button is a neutral Stop until something is typed; with a draft, Stop is in the ⋯ menu and `/stop`. Messages sent mid-reply wait as rows above the composer instead of looking like sent messages in the conversation. In a half-width pane the chips fit without scrolling sideways, and Continue in Terminal moved to the ⋯ menu. (#3508)
