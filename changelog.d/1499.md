### Fixed

- **The daemon works again on Windows builds without `wmic.exe`.** Current
  Windows 11 has removed wmic, which the daemon used to read the boot time and
  which process owns a pid. Every daemon restart looked like a reboot, orphaned
  shells from earlier sessions were never cleaned up, and every identity-checked
  kill was skipped. These reads now go through CIM, and values saved by older
  versions still match. (#1499)
