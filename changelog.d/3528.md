### Fixed

- **The editor tab keeps what you type in Edit mode.** Switching Edit -> View -> Edit used to reset the text, and closing the tab from View dropped it without asking. Edit mode is now a scratch copy kept in the tab, shown in View too. A header chip says it is not saved to disk, Reload asks before discarding it, and closing the tab asks from either mode. Closing its pane (the close-pane shortcut, Fleet's close) or its workspace asks too. Nothing is written to disk.
