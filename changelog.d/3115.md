### Changed

- **On macOS and Linux, an agent's pane identity is checked against the
  process that connected.** When a tool call names a process other than the
  one the operating system reports for the connection, wmux no longer gives it
  the identity of a pane that process is not in. Calls relayed by the MCP
  broker, and processes that run outside any pane, behave as before. Windows is
  unchanged for now.
