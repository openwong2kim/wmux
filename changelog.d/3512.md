### Fixed

- **Deliveries reach long-running Claude Code panes again.** wmux checks a
  pane's screen before it types an A2A task or a `send_message` into it, and
  rebuilds that screen from the pane's recent output. In a pane that had been
  running for hours, rows Claude Code drew once and never redrew could no
  longer be rebuilt, and wmux held deliveries to an idle pane as unconfirmed.
  wmux now keeps one compact snapshot of each full-screen pane's grid and
  rebuilds the screen from it. A pane whose screen still can't be confirmed is
  redrawn once, the next time it is idle. Until then, chat send and Rewind say
  that wmux can't confirm the input is empty yet, rather than reporting a
  draft.
