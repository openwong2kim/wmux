Channels now separate task records from shared discussions. Linked mission channels show the task title, open/closed/detached state, branch, workspace shortcut, and latest visible activity before an expandable discussion history. Search still opens the history directly. Ordinary channels explain their shared-context purpose, and the composer explains that a post without an agent mention adds to the shared record.

Task state comes from the existing mission cache; closed missions and recent messages are not treated as verified completion. Existing channel membership, delivery, search, archive, and trash behavior is preserved.

Visual refinement reuses the existing Orca-inspired navigation and MIT assistant-ui composer treatment: readable task rows, a stronger title hierarchy, a flat activity timeline, expandable long reports, and theme-aware narrow-dock styling. Task comments retain channel-specific mention and delivery behavior.
