### Fixed

- **Browser automation keeps finding a free debugging port.** wmux now gives
  back its debugging-port reservation when it quits, including a second launch
  that only hands over to the running window and a Windows sign-out or
  shutdown. After a restart it no longer mistakes a leftover reservation for a
  running wmux just because Windows reused the process id. Before, leftovers
  piled up and could crowd out the range, so two windows ended up on one port
  with browser tools dead. (#3287)
