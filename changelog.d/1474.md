### Fixed

- **A Claude Code permission prompt now shows "Needs you".** A pane sitting on
  `Do you want to proceed?` often stayed on its running or idle dot. Claude
  Code draws that row with cursor moves on some frames. A review panel that
  checked for the `codex` binary made the pane count as Codex for the rest of
  the session. A pane started in the default permission mode never got
  recognised as Claude. All three are fixed. Re-run `wmux setup-hooks` (or
  the in-app hook install) to also register Claude Code's `PermissionRequest`
  hook, which marks the pane the moment the dialog opens. It only changes the
  pane's status and never sends an approval card to your phone (#1474).
