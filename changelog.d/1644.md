### Added

- **Inline images in the browser terminal.** The page `wmux web` serves (and the phone) now draws sixel and iTerm2 (OSC 1337) images too, with limits sized for a phone. Browsers that cannot run the image decoder keep showing plain text. Turn it off with `wmux web --no-inline-images`; like the other options, the choice is kept across re-runs and daemon restarts. (#1641)
