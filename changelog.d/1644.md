### Added

- **Inline images in the browser terminal.** The classic browser terminal that `wmux web` serves (`/classic`) now draws sixel and iTerm2 (OSC 1337) images too, with limits sized for a phone. The browser app at `/` keeps them off for now. Browsers that cannot run the image decoder keep showing plain text. Turn it off with `wmux web --no-inline-images`; like the other options, the choice is kept across re-runs, daemon restarts and `--stop`, and a connected phone picks it up when it reconnects. The browser terminal no longer forwards its own answers to device queries in the pane output to the pane. (#1641)
