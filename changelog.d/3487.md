### Changed

- **The terminal service keeps each session's older output compressed, on the Rust engine too.** Every session's output ring used to hold its full 8 MB raw on the Rust terminal engine, and `session.ringCompression` did nothing there. Now each finished 256 KB chunk is compressed with zstd, and the output a pane is still drawing stays as it was. On a benchmark of six 8 MB sessions, ring memory fell from 48 MB to 5 MB for agent-style output and to 13 MB for diff-heavy output. The amount of history kept and replayed is unchanged, and every read, snapshot and saved `.buf` file holds the same bytes as before. Compression is on by default. Turn it off with `session.ringCompression: false` in `config.json`. The `false` that older versions wrote into `config.json` by default is removed once, on first start. (#3487)
