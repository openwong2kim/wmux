워크스페이스 타일 — cmux vs Orca vs wmux

세 제품의 사이드바 타일을 실물 소스 기준으로 재구성한 근사 목업입니다 (cmux = manaflow-ai/cmux ★26k Swift/AppKit · Orca = stablyai/orca ★49k Electron/React · 2026-08-20 HEAD 직독). 스크린샷이 아니라 코드에서 읽은 구조를 그린 것입니다.

cmux — 요청자가 "단순하다"고 기억하는 그 앱

실제로는 타일에 wmux보다 더 많은 것이 실린다. 다만 전부 사용자 설정으로 끌 수 있고, 상태가 단어로 읽힌다.

상태 모델

  • 5레인 단어: Todo · Working · Needs Attention · In Review · Done (WorkspaceTaskStatus)
  • 신호에서 자동 추론(입력대기 > 실행중 > PR열림 > 머지됨 > dirty) + 수동 오버라이드 + 순환 단축키
  • 글리프 = 진행률 파이(0%→50%→75%→100%+체크)

타일 위 클릭 요소

  • PR 행(onOpenPullRequest), 포트(onOpenPort), 상태 메뉴, 체크리스트 추가/토글/첨부, Show more 토글, URL 링크
  • → "클릭 요소 없음"은 사실이 아님

노출 제어

  • 개별 토글 6개(metadata·log·progress·branch·PR·ports) + 마스터 "Hide all details" 스위치
  • hide-all이면 제목+상태 한 줄로 압축(SidebarRowCompactStatusLine)

Orca — 사이드바가 칸반 레인

상태를 카드에 쓰는 대신 그룹핑으로 표현 — 카드가 상태 레인 아래에 정렬된다. 카드 자체에도 클릭 요소가 많다.

  • 5상태: working(스피너) · permission(? 아이콘) · active/done(에메랄드 점) · inactive(회색 점) — StatusIndicator.tsx
  • 단어는 툴팁 + 칸반 레인 헤더로 (WorkspaceKanbanStatusLane)
  • unread는 상태 글리프 위 앰버 점 오버레이 + 벨 토글 버튼

카드 위 클릭 요소

  • unread 벨 버튼, PR/리뷰 아이콘, 포트(WorktreeCardPorts 320줄), 에이전트 섹션(WorktreeCardAgents 421줄), lineage 접기
  • → 여기도 "클릭 요소 없음"은 사실이 아님

노출 제어

  • 카드별 display 메뉴 (WorktreeCardDisplayMenuSection) + 상태 표시/숨김 popover

wmux — 현행 + A안

정보량은 셋 중 중간. 진짜 격차는 정보가 아니라 ①클릭 소유권 ②상태 단어 ③노출 설정 부재다. A안이 ①②를 해소한다.

  • cmux의 Review·Done 레인 같은 작업 수명주기 개념은 없음 (wmux 상태는 에이전트 활동, cmux 상태는 작업 단계)

타일 위 클릭 요소

  • 현행: 풀폭 디스클로저·포트 주소·PR·기어 5종이 rest에서 가로챔
  • A안: › 2 칩 + 호버 칩/아이콘만. rest 기준 셋 중 가장 깨끗

노출 제어

  • 없음 — 토글도 마스터 스위치도 없다. 셋 중 유일

한 줄 비교

cmuxOrcawmux (A안)
상태 표현 단어 5레인 + 진행률 파이 (작업 수명주기) 아이콘 구분 + 칸반 레인 그룹핑 dot 6종 + 단어 (에이전트 활동)
타일 클릭 요소 많음 (PR·포트·체크리스트·상태 메뉴) 많음 (벨·PR·포트·에이전트·lineage) A안: 최소 (칩 1 + 호버)
노출 제어 토글 6개 + 마스터 hide-all 카드별 display 메뉴 없음
"클릭 없는 단순 타일" 설정으로 도달 가능 (기본값 아님) 불가 (카드가 곧 대시보드) A안이 기본값으로 제공

시사점

  1. 요청자의 cmux 기억은 부정확하다. cmux 타일에는 클릭 요소가 wmux보다 많다. 그가 경험한 "단순함"의 정체는 Hide all details 설정 — 끄면 제목+상태 한 줄이 된다. "클릭 요소를 다 없애라"가 아니라 "끌 수 있게 하라"가 cmux의 실제 답이다.
  2. 상태를 단어로 읽게 하는 건 셋 다 동의하는 방향. cmux는 행 안의 단어, Orca는 레인 헤더, wmux A안은 레일 단어. A안은 이 합의선에 정확히 올라탄다.
  3. wmux만 노출 다이얼이 없다. A안 출시 후, cmux식 "Hide details" 마스터 토글 1개(개별 6토글 말고)를 후속 이슈로 떼면 요청자 같은 미니멀 취향까지 커버된다 — B안(정보 삭제) 없이.
