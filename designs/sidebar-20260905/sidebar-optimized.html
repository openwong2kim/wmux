색 문법 (DESIGN.md 준수)

  1. amber = running만. 워크스페이스 점 + 에이전트 행 점 + 푸터 "1 running"이 한 계열. 화면 amber 지점 12+ → 1.
  2. 빨강 = needs you. 점 + 행 wash + "답변 대기" 텍스트 = 2 렌디션 상한 준수. error는 점 대신 ✕로 형태를 바꿔 구분.
  3. git dirty는 muted 숫자. "·41"은 정보로 남고 경보로는 안 읽힌다. ↑↓만 색 유지(오너 2026-07-20 신호등 결정).
  4. steel = 선택. 선택 행 왼쪽 2px 스틸 엣지. 컬러 태그 바는 비선택 행에서만.

폭·밀도

  1. 이름은 Inter 500, 상시 풀폭. 톱니·^N·에이전트 수·액션은 선택/호버 행에서만 나타남 → "3. autodesignsite" 완전 표시.
  2. 안 읽음 = 굵기 + 알약. Orca처럼 볼드로 1차, 숫자 알약은 그대로(위치만 이름 바로 뒤).
  3. 조용한 행은 text-sub. 12h 이상 idle은 이름 자체를 한 단계 낮춰 "지금 살아있는 곳"이 구조로 드러남.
  4. branch 행은 10.5px, 풀 브랜치명. "⎇ …" 같은 무의미 잘림 제거(툴팁 아닌 본문에서 읽힘).

Orca·herdr에서 가져온 것 / 안 가져온 것

  1. 가져옴: herdr의 상태 롤업(에이전트 blocked → 워크스페이스 행 전체가 blocked로 보임), Orca의 unread=볼드, Needs-You 상단 고정(토글).
  2. 안 가져옴: Orca 칸반 대시보드(240px에 안 맞음), herdr의 done-until-viewed(wmux는 이미 알약이 그 역할).
  3. wmux만의 것 유지: 브랜치·git 동기화·페인 ID·^N 점프. 둘 다 없는 정보라 버리지 않고 색만 낮췄다.
