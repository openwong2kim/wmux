What each product does

SearchCursorIATake
Windows Terminal Pinned search in the left nav. Filters profiles + categories. Appearance card: shape dropdown + color. Visual, next to other look controls. Profile tree + category list. Save / Discard footer. Search belongs in the nav, not a hidden command. Cursor is an Appearance control, not a hidden Terminal flag.
Cursor Dedicated Settings page has its own search. VS Code Settings is a second, fully indexed list. Editor cursor lives in VS Code Settings (search “cursor”). Not in the Cursor-product page. Product settings (General, Agents, Models, MCP, Rules…) are a different surface from editor settings. One searchable surface. We should not split “app settings” and “terminal look” the way Cursor splits product vs VS Code.
Orca Cmd-, then type. Matches native-language synonyms (언어 / language). Settings → Terminal: font, theme, cursor style, padding. ~16 panes. Docs deep-link to a pane. Experimental is its own pane. Search must accept Korean synonyms. Cursor sits with font. Do not grow a 16-pane zoo.
Herdr No in-app search. Config reference is the index. herdr --default-config. No shape picker. Experimental CJK IME cursor reveal lives in toml only. Small TUI popup: theme, sound, toast, Integrations. First-run opens Integrations. Experimental stayed out of the TUI on purpose. Keep Settings for things a human flips. Leave power/experimental out of the left nav. Integrations is a first-class tab, not buried in General.
wmux today None. Nine tabs, 160px nav, walk-and-hope. None. Font is in Appearance; terminal behavior is in Terminal. Full-bleed (good). Claude Integration vs Agents is the confusing split. Browser rows live in Terminal. Footer hint is dead chrome. Keep full-bleed + instant apply. Add search and a visual cursor. Group the nav. Do not add a Save bar.

Proposal in this mock

  • Search in the left nav (WT). Index label + description + synonyms, including Korean. Click a hit → switch tab, scroll, steel flash.
  • Visual cursor cards in Appearance, next to font (WT Appearance + Orca Terminal). Block default. Color stays on the theme’s --accent-cursor — no extra color picker this round.
  • Grouped 9-tab nav, same count as today. Claude Integration renamed Accounts. LAN Link under System as Network. Browser stays a section inside Terminal, not a tenth tab.
  • No inventory cut. Language stays the full 23-locale grid from today. Other controls that look thinner here are sketch shorthand, not a proposal to delete them.
  • No Save/Discard. Instant apply, like today. No experimental dump (Herdr lesson).
